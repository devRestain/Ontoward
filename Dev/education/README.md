# 원문 발췌 도구의 현재 경계

D18에서 이전 지침 기반 교육 발췌·매핑·검토 초안과 그 임시 사본을 삭제했다. 원래 지침 문서와 탐색 카탈로그는 assets/guidelines/에 보존한다.

이 디렉터리의 일반 원문 발췌 코드는 현재 원천 전용 온톨로지 생성 경로에서 사용하지 않는다. 삭제한 배치를 재개하거나 이전 승인을 재사용하지 않는다. 현재 준비는 [SNOMED CT·BODHI-S 생성 도구](../ontology/README.md)를 따른다.

상담 중 공통 교육·이해 확인·설명 정정은 D17의 일반 워크플로우 동작이며, 삭제된 질환별 교육 초안과 별개다. 실제 원천 후보·한국어 처리·임상 승인·실행 수용의 상태는 [루트 상태](../../PROJECT_STATE.md)와 [데이터 상태](../../data/PROJECT_STATE.md)가 관리한다.
