# Temporary Workspace Contract

## Ownership

- Use this directory for disposable project scratch, run inputs, drafts, and local inspection evidence.
- Keep persistent preparation responses, checkpoints, mappings, and review results in root data/.
- Keep credentials and Codex state outside this directory.

## Workflow

- Use task-specific subdirectories and preserve unrelated scratch.
- Use codex/ for current CLI scratch and packaging/ for generated submission archives.
- Treat scratch presence as temporary evidence rather than source admission or a submitted artifact.
- Keep cleanup independent of extraction resume and follow the user's explicit disposition of preparation records.

## Handoff

- Record Tmp-related operational progress in root PROJECT_STATE.md without adding a state scope.
- Exclude scratch and local backups from submission artifacts.
