# Korean Journal Clinical Documents Contract

## Content Meaning

- Treat `kr_journal_*.md` as journal-derived guidance, recommendations, consensus documents, evidence reviews, and summaries.
- Distinguish converted XML, PDF, HTML, and abstract-only web sources through the catalog format field.
- Read language metadata because the collection contains Korean and English material.

## Retrieval Use

- Use the authoring society, article date, and document type to identify the role of a clinical statement.
- Treat abstract-only documents as limited source material rather than complete guideline text.
- Check DOI-derived filenames and source URLs when identifying article overlap.

## Source Handling

- Preserve article-specific Creative Commons metadata, including any ND or NC conditions.
- Inspect conversion and missing-body limits before extracting recommendations.
