# SNOMED CT 준비 결과

이 디렉터리는 `Dev/ontology/snomed/`가 만든 RF2 SQLite, 릴리스 manifest, 버전·해시 기반 어휘 후보와 고정 registry, 질환–Target packet, 모델 원응답, 검토 기록, 일일 호출 장부와 preview Turtle을 보관합니다.

실제 호출은 실행 옵션으로 명시하고 일일 잔여량을 제공해야 합니다. 원응답은 구조·근거 검증 전에 저장합니다. 현재 Turtle은 `preview_only`이며 임상 검토와 제출 지식 수용을 뜻하지 않습니다. 원본 RF2와 이 결과의 공유·이동은 SNOMED 이용 조건을 따릅니다.
